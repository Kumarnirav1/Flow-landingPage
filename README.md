# Flowly – Responsive Landing Page

A responsive landing page built with plain HTML, CSS and JavaScript. No frameworks or libraries.

**Live demo:** [add your GitHub Pages link here]

![Screenshot](images/screenshot.png)

## Features

- Mobile-first responsive layout (phones, tablets, desktops)
- Sticky navigation with a hamburger menu on small screens
- Smooth scrolling and active-section highlighting
- Call-to-action buttons in the hero, nav and signup section
- FAQ accordion
- Email validation on the signup form
- Light/dark theme toggle (also follows system preference)

## Tech Used

- HTML5 (semantic elements)
- CSS3 (Flexbox, Grid, custom properties, media queries)
- JavaScript (DOM manipulation, event handling, IntersectionObserver)
